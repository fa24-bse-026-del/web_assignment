CSS Positioning and Stacking

Lecture 7

Lecture Summary

CSS positioning is used to control the location of elements on a web page.

Normal Flow

In normal flow, elements are displayed according to their position in the HTML document.

Position Types

  • Static
  • Relative
  • Absolute
  • Fixed
  • Sticky

Z-Index

The z-index property controls the stacking order of positioned elements.

Floats

Floats can move elements to the left or right. Clearing can be used to control the effect of floats.
