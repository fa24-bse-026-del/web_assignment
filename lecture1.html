Lecture Summary

Web development is the process of creating websites and web applications.

Internet and Web

The Internet is a global network that connects computers and devices. The Web is a service that works through the Internet.

Client-Server Model

A client sends a request to a web server. The server processes the request and sends a response back to the client.
